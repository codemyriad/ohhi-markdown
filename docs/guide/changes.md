# What's new

The changes in each release, newest first. The version you are running is
in the Help menu, at the bottom.

## October 2026 — first run, sharing and help

**Help is in the app**

- A **Help** menu (the question mark at the toolbar's right end): getting
  started, keyboard shortcuts, what to do when something goes wrong, sharing
  and the relay, and this page.
- **Report a problem…** copies a short report — your sentence plus the
  version, the vault, the relay's state, the open note's sync state and the
  last events from the Log — for you to paste in the team chat. It never
  includes what your notes say, and the app sends it nowhere by itself.
- The menu's last line says which version you are running and what the last
  update check found: *up to date* only when it found nothing newer.
- When an update has installed, its notice has a **What changed** button
  beside *Restart*.
- These guide pages are served with the app, so they work wherever the app
  does.

**Sharing**

- Share links can be web addresses, and can carry the folder's name and the
  name of the person who sent them (the name they typed, not a verified
  account).
- Adding a shared folder says "Adding *folder*" while it arrives, rather than
  "Linking this device"; choosing to put it in a vault of its own explains the
  folder picker before it opens.
- The Shared view's empty state names the relay your shares will use.
